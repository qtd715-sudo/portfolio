01 · Problem (As-Is)

문제 정의 — 사람마다 다른 "잘 쓴 매뉴얼"

SaaS 제품 매뉴얼을 모듈 × 포털(구매사·협력사) × 언어(국·영) 조합으로 만들고 버전업합니다. 한 권은 90~100쪽입니다(협력사 완성본 기준 국문 91쪽, 영문 95~96쪽).

기존 수작업 공정

화면 캡처→ 항목(라벨) 옮겨 적기→ 원고 작성→ 영문 번역→ Word 양식 맞춤→ 상호참조·캡션·아이콘→ 검수

문서로 확인되는 5대 병목

B1 · 기준

기준 불일치

"잘 쓴 매뉴얼"의 기준이 사람마다 달라 문체·금지어·양식이 판마다 흔들림

B2 · 정합성

서술 ↔ 실제 동작 불일치

매뉴얼 서술과 실제 제품 동작(소스·화면)이 어긋남

B3 · 화면

Canvas 그리드

화면 그리드가 canvas로 그려져 라벨·데이터가 DOM에 없음 — 눈으로 옮겨 적어야 함

B4 · 이미지

캡처 해상도 기준 모호

"원본 픽셀" 기준이라 Word에 넣으면 흐림

02 · Architecture

시스템 아키텍처 — 두 세션, 한 장의 계약

화면을 다루는 세션과 문서를 다루는 세션을 나누고, 두 세션은 문서로만 일을 넘깁니다. 모든 도구 실행은 훅이 먼저 검문하고, 사람이 고친 판은 야간 배치가 정답 자료로 바꿉니다.

← 좌우로 밀어서 보기 →

점선 상자 = 세션 경계. 주황 = 사람 피드백이 규칙으로 돌아오는 경로(승인 전에는 규칙이 스스로 바뀌지 않음).

세 층 구조 — 누가 무엇을 결정하나

Layer 1 · 생성

LLM (Claude)

원고 작성 · 국→영 문형 적용 · 사람 눈 검토 · 도구 선택

판정은 하지 않는다

Layer 2 · 판정

규칙 엔진 (Python · 정규식)

합격/불합격 판정, Word XML 편집. 같은 문서면 같은 결과

결정론적 — 재현 가능

Layer 3 · 기준

모범본 기준선

납품 완료 국·영 매뉴얼 10쌍의 실측값 과반 = 규칙

모델 재훈련이 아닌 데이터 기준

사람의 자리. 목차 컨펌 · 작업 범위 · 갈리는 문형 결정 · 개선 후보 승인 · 최종 검수. 자동화가 사람을 빼는 것이 아니라, 사람이 판단해야 하는 지점만 남기도록 설계했습니다.

03 · Prompt · Guardrail · Word Engine

프롬프트·가드레일·Word 편집 엔진 설계

지침은 "읽으면 좋은 것"에 그치기 쉽습니다. 그래서 규칙은 문서 한 곳에 두고, 지켜야 하는 것은 훅과 스크립트로 강제했습니다.

컨텍스트 우선순위 (명문화)

작성 가이드 v2>문체·금지어 규칙>핸드오프 계약>커맨드>에이전트>스킬>메모리

가이드가 완성본 실측과 다르면 실측으로 가이드를 고칩니다. 137KB짜리 통합 지침(v1)을 151줄 인덱스 + 장별 문서 9종(약 3,500줄)으로 분리했고, 개정 근거는 날짜로 남깁니다(작성 가이드 24일·179건, 인덱스 20일·49건).

PreToolUse 훅 3종 — 지침이 아닌 시스템으로 막기

guard_docs76줄

규칙 문서 3종(영문 작업이면 + 국영 문형대조)을 읽은 기록이 없으면 Word 도구 실행을 막습니다.

차단 대상: 규칙 미독 상태의 Word 빌드
guard_scripts56줄

지난 작업 폴더의 임시 스크립트를 복사하거나 실행하지 못하게 막고, 새 스크립트는 허락 창을 띄웁니다.

차단 대상: 옛 버그를 품은 스크립트 재사용
guard_latest101줄

사용자가 마지막으로 고친 판(.docx1 · 열린 Word)이 아닌 옛 판을 바탕으로 빌드하거나 지시하면 막습니다.

차단 대상: 사람 수정 내용의 되돌림

Word XML 직접 편집 엔진

제약

  • XML만으로는 줄바꿈·쪽 끝 같은 실제 레이아웃을 알 수 없음

설계

  • docx 내부 XML을 파이썬으로 직접 편집하고 zip으로 다시 저장 — Word 프로그램을 거치지 않음
  • 원본 불변: 모든 도구는 새 파일(_N)로 저장, 손대지 않은 장은 원본과 차이 0 검증
  • 레이아웃 판정 도구(버튼 줄바꿈 · 빈 쪽 · 표 칸 단어 끊김)를 마무리 체인에 고정

마무리 후처리 체인 finish_all.py — 국·영 동시 실행, 단계별 시간 기록

빈 줄→표 칸→상호참조→캡처 크기→버튼 줄바꿈→쪽 끝

금지어 단일 정답 표 — 검사 7종이 한 곳을 읽는다
